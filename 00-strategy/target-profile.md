# Целевой профиль

Собрано из сессии «Занятие и заметки» и скорректировано по [[vacancy-analysis]].

## Позиционирование

**Backend Engineer (Python), близкий к AI / LLM-интеграциям.** Уровень — Middle+ сейчас, Senior как цель через 1–2 года. Сеньорные AI-позиции (Магнит Tech, Бюро 1440) — цель второго горизонта.

## Что рынок подтвердил

- Python-бэкенд + LLM — один из самых живых сегментов спроса.
- Docker и CI/CD — базовая гигиена.
- Системный дизайн и глубина БД — требование №1 после Python.
- Агентная разработка — способ работы по умолчанию, не отдельный навык; о ней прямо спрашивают.

## Что оказалось слабее, чем думали

- Облака: 1 из 7 вакансий, только международная. Для РФ-рынка — отложить. Kubernetes важнее.
- Классический MLOps и глубокий ML: на уровне «понимать», не «уметь».
- Фронт: 0 из 7. Из плана убрать совсем.

## Чего не было в наброске, а рынок просит

Kafka, Redis, Alembic, тестирование, observability, обработка отказов (таймауты/ретраи/идемпотентность), оптимизация запросов.

## Что отличает сеньора (а не просто стек)

- Системный дизайн и распределённые системы.
- Глубина БД: индексы, планы, транзакции, блокировки.
- Очереди, кэширование, проектирование API.
- Надёжность: SLO, observability, разбор инцидентов.
- Безопасность: аутентификация, секреты, базовые OWASP-риски.
- Умение ревьюить код (в том числе сгенерированный), ставить задачи агенту, понимать, где ему нельзя доверять.

## Целевой рынок

РФ: 300–400 тыс. ₽ на руки, удалёнка. Международная удалёнка (Constructor: $80–120k, английский C1) — через 1–2 года, тогда в план добавляются [[english]] и [[cloud-terraform]].
