# Из чего состоит собес на Middle+/Senior Python

Типовая воронка на российском рынке (банки, X5, Циан, Авито, Яндекс) — 3–5 этапов. Зная секции, можно готовиться прицельно.

## Этапы

| Этап                         | Длительность | Что проверяют                                                                                                     | Какие заметки                                                     |
| ---------------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| HR-скрининг                  | 20–30 мин    | Мотивация, зарплатные ожидания, формат, стаж                                                                      | [self-presentation](self-presentation.md)                                             |
| Технический скрининг         | 45–60 мин    | Python в глубину, БД, базовые вопросы по стеку. Иногда с маленьким live coding                                    | [_python-core](../10-python-core/_python-core.md), [_databases](../20-databases/_databases.md), [python-live-coding-tasks](../90-live-coding/python-live-coding-tasks.md)    |
| Live coding / алгоритмы      | 60 мин       | Писать код в шаред-редакторе, рассуждать вслух. В банках и Яндексе — алгоритмы; в продуктовых — прикладная задача | [_live-coding](../90-live-coding/_live-coding.md)                                                  |
| Системный дизайн             | 60 мин       | Спроектировать сервис: нагрузка, хранение, очереди, отказоустойчивость                                            | [_system-design](../80-system-design/_system-design.md)                                                |

## Что отмечено в разобранных вакансиях

- **Циан** прямо спрашивает на собесе про использование AI-инструментов в разработке и ревью сгенерированного кода → [ai-assisted-development](../70-llm-engineering/ai-assisted-development.md).
- **Циан** может попросить СТД-Р (выписку о трудовой деятельности) для подтверждения стажа → формулировать опыт так, чтобы он сходился с документами, см. [self-presentation](self-presentation.md).
- **Банки** (Альфа, скрытый банк) — упор на БД, Kafka, отказоустойчивость, безопасность.
- **X5 / Циан** — оптимизация производительности, профилирование → [memory-performance](../10-python-core/memory-performance.md), [query-optimization-n-plus-1](../20-databases/query-optimization-n-plus-1.md).
- **Constructor.io** — английский C1, ML-инфра; реалистично через 1–2 года.

## Как проходит типовой технический скрининг (60 мин)

1. 5 мин — рассказ о себе.
2. 15–20 мин — Python: модель данных, GIL, asyncio, генераторы.
3. 15 мин — БД: индексы, транзакции, N+1, миграции.
4. 10 мин — стек/инфра: Docker, очереди, тесты.
5. 5–10 мин — твои вопросы.

## Какие вопросы задавать интервьюеру

Хорошие вопросы — тоже сигнал сеньорности. 3–4 заготовки:
- Как устроен процесс ревью и деплоя? Как часто релизитесь?
- Какой самый болезненный технический долг сейчас?
- Как в команде используют AI-инструменты, есть ли правила?
- Как измеряется успех для этой роли через полгода?
