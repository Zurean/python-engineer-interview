# Из чего состоит собес на Middle+/Senior Python

Типовая воронка на российском рынке (банки, X5, Циан, Авито, Яндекс) — 3–5 этапов. Зная секции, можно готовиться прицельно.

## Этапы

| Этап                         | Длительность | Что проверяют                                                                                                     | Какие заметки                                                     |
| ---------------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| HR-скрининг                  | 20–30 мин    | Мотивация, зарплатные ожидания, формат, стаж                                                                      | [[self-presentation]]                                             |
| Технический скрининг         | 45–60 мин    | Python в глубину, БД, базовые вопросы по стеку. Иногда с маленьким live coding                                    | [[_python-core]], [[_databases]], [[python-live-coding-tasks]]    |
| Live coding / алгоритмы      | 60 мин       | Писать код в шаред-редакторе, рассуждать вслух. В банках и Яндексе — алгоритмы; в продуктовых — прикладная задача | [[_live-coding]]                                                  |
| Системный дизайн             | 60 мин       | Спроектировать сервис: нагрузка, хранение, очереди, отказоустойчивость                                            | [[_system-design]]                                                |
| Архитектурная секция / опыт  | 60 мин       | Разбор твоих проектов, решения, трейдоффы. Здесь же часто про AI-инструменты                                      | [[stories]], [[architecture-layers]], [[ai-assisted-development]] |
| Behavioral / с руководителем | 30–60 мин    | Конфликты, ошибки, рост, как работаешь в команде                                                                  | [[stories]]                                                       |
| Финал / оффер                | —            | —                                                                                                                 | —                                                                 |

## Что отмечено в разобранных вакансиях

- **Циан** прямо спрашивает на собесе про использование AI-инструментов в разработке и ревью сгенерированного кода → [[ai-assisted-development]].
- **Циан** может попросить СТД-Р (выписку о трудовой деятельности) для подтверждения стажа → формулировать опыт так, чтобы он сходился с документами, см. [[self-presentation]].
- **Банки** (Альфа, скрытый банк) — упор на БД, Kafka, отказоустойчивость, безопасность.
- **X5 / Циан** — оптимизация производительности, профилирование → [[memory-performance]], [[query-optimization-n-plus-1]].
- **Constructor.io** — английский C1, ML-инфра; реалистично через 1–2 года.

## Как проходит типовой технический скрининг (60 мин)

1. 5 мин — рассказ о себе.
2. 15–20 мин — Python: модель данных, GIL, asyncio, генераторы.
3. 15 мин — БД: индексы, транзакции, N+1, миграции.
4. 10 мин — стек/инфра: Docker, очереди, тесты.
5. 5–10 мин — твои вопросы.

## Какие вопросы задавать интервьюеру

Хорошие вопросы — тоже сигнал сеньорности. 3–4 заготовки:
- Как устроен процесс ревью и деплоя? Как часто релизитесь?
- Какой самый болезненный технический долг сейчас?
- Как в команде используют AI-инструменты, есть ли правила?
- Как измеряется успех для этой роли через полгода?
