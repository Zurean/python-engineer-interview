# Конвенции волта

Эти правила нужны, чтобы заметки можно было дописывать и углублять точечно, не ломая структуру и не теряя твои пометки.

## Структура папок

- Папки с числовым префиксом (`10-python-core`) — это **тема-хаб**. Внутри: файл-хаб `_имя.md` плюс заметки-подтемы.
- Хаб содержит: зачем тема нужна на собесе, порядок прохождения подтем, таблицу подтем (Dataview + ручной список).
- Вложенность не глубже двух: хаб → подтема. Если подтема разрастается — она становится новым хабом с собственной папкой, а старая заметка оставляет ссылку. Так структура не «перекраивается», а наращивается.

## Имена файлов

- Латиница, kebab-case, уникальные во всём волте (Obsidian резолвит `[[ссылки]]` по имени файла без папки). Внутри — русские заголовки.
- Хабы начинаются с `_`, чтобы быть первыми в списке папки.

## Шаблон заметки-темы

```markdown
---
type: topic
title: Название
tier: 1
impact: 5
effort: 3
status: todo
confidence: 0
tags: [python, tier1]
updated: 2026-10-29
---

# Название

> **Зачем на собесе:** одна-две фразы — в какой секции и как именно это спрашивают.

## Минимум для собеса
Тезисы, которые надо уметь проговорить.

## Вопросы с собесов
- [ ] Вопрос → *краткий ориентир ответа*

## Углубление
Нюансы и внутренности. Может быть пустым со стабом «запросить углубление».

## Ресурсы
Книги, доки, статьи.

## Связи
[[ссылки]] на смежные темы.

## Мои заметки
(пусто — заполняет владелец волта; при переписывании никогда не трогается)
```

## Запросы на дописывание

Для создания развёрнутых учебных материалов использовать [[theory-note-template]]. Исходная заметка темы остаётся карточкой, единицей прогресса и точкой входа, а крупная теория при необходимости выносится в связанные заметки рядом с ней.

Чтобы Claude (или любой ассистент) мог точечно править волт, запрос формулируется в терминах **файл + раздел**:

- «Углуби раздел *Углубление* в `transactions-isolation-locks`» → перезаписывается только этот раздел.
- «Добавь в *Вопросы с собесов* в `kafka` вопросы про exactly-once» → добавляются пункты, существующие чекбоксы и их состояние сохраняются.
- «Разверни `redis` в отдельный хаб» → создаётся папка с хабом и подтемами, старая заметка становится ссылкой-редиректом.
- «Пересобери минимум в `asyncio` под Senior» → перезаписывается только «Минимум для собеса».

Правила для ассистента при правках:
1. `## Мои заметки` не трогать никогда.
2. Состояние чекбоксов (`[x]`) сохранять.
3. Frontmatter менять только по явной просьбе (кроме `updated`).
4. Имена файлов и существующие ссылки не переименовывать без просьбы.
5. Новые заметки добавлять в хаб и в [[progress]].

## Чекбоксы

- В заметках тем чекбоксы = «могу ответить на этот вопрос без подготовки».
- В [[progress]] чекбоксы = тема закрыта на уровне минимума (дублирует `status: done`, держать в синхроне вручную или забить на одно из двух).
