# Как пользоваться волтом

## Один цикл работы (≈ 1 сессия 1–2 часа)

1. Открой [[Home]] → таблица «Что взять следующим». Или просто возьми верхнюю незакрытую тему из [[pareto-plan]].
2. Открой заметку темы. Поставь в frontmatter `status: in-progress`.
3. Прочитай раздел **«Минимум для собеса»** — это то, что надо уметь проговорить вслух. Не читай «Углубление», пока не закрыт минимум.
4. Пройди чеклист **«Вопросы с собесов»**: на каждый вопрос ответь вслух (или письменно, 3–5 предложений) *без подглядывания*. Смог — ставь `[x]`. Не смог — читай, затем через день возвращайся.
5. Что удивило, что не знал, формулировки, которые понравились — пиши в **«Мои заметки»** внизу заметки. Этот раздел никогда не перезаписывается.
6. Когда все вопросы минимума закрыты и ты можешь объяснить тему за 5 минут без подготовки — `status: done`, `confidence: 2`. `confidence: 3` ставь только после реального собеса, где тему спросили и ты ответил.
7. Строчку в [[log]]: дата, тема, что сделано.

## Правило Парето

Приоритет всегда такой: **закрыть минимум по всем темам уровня 1 → минимум уровня 2 → углубление уровня 1 → остальное.** Не проваливаться в «Углубление» одной темы, пока по соседней теме уровня 1 не закрыт минимум. Гринд по тонкостям CPython — это нормально и полезно, но после того, как по всем темам уровня 1 есть уверенный «минимум».

## Три уровня глубины в каждой теме

| Раздел | Что это | Когда читать |
|---|---|---|
| Минимум для собеса | 5–10 тезисов, которые надо уметь проговорить | Всегда, сначала |
| Вопросы с собесов | Чеклист реальных/типовых вопросов | Сразу после минимума |
| Углубление | Нюансы, внутренности, edge cases | Когда минимум закрыт по всему уровню |

## Поля frontmatter

| Поле | Значения | Смысл |
|---|---|---|
| `tier` | 1 / 2 / 3 | Уровень важности из [[vacancy-analysis]] |
| `impact` | 1–5 | Насколько сильно тема влияет на результат собеса |
| `effort` | 1–5 | Сколько усилий закрыть минимум (1 = вечер, 5 = недели) |
| `status` | todo / in-progress / done | Прогресс по теме |
| `confidence` | 0–3 | 0 не трогал, 1 читал, 2 могу объяснить, 3 отвечал на реальном собесе |

Поля можно менять прямо в Properties-панели Obsidian или руками в тексте.
