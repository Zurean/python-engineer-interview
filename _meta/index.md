# Карта проекта и память агента

Эта заметка — входная точка для понимания устройства проекта и продолжения работы в новой сессии. Пользовательская главная страница — [[Home]].

## Быстрый старт для агента

1. Прочитать `AGENTS.md` в корне проекта.
2. Открыть [[state]] и продолжить незавершённую работу.
3. Проверить приоритеты и критерии в [[tasks]].
4. Для теоретических материалов следовать [[theory-note-template]].
5. Перед коммитом синхронизировать [[tasks]], эту карту и [[state]].

## Память и инструкции

- `AGENTS.md` — обязательные правила работы агента, безопасность редактирования и рабочий цикл.
- [[tasks]] — активные и отложенные задачи проекта.
- [[state]] — последнее изменение, текущая работа, следующий шаг и блокеры.
- [[theory-note-template]] — назначение, структура и критерии качества теоретических конспектов.
- [[conventions]] — общие конвенции структуры и редактирования волта.
- [[how-to-use]] — пользовательский цикл обучения.
- [[sources]] — происхождение программы и материалов.

## Сквозная практика

- [[rag-service-project]] — проект, связывающий большую часть тем уровней 1–2 и создающий материал для портфолио и рассказа на собеседовании.

## Текущий маршрут развития содержимого

1. Пилотный теоретический модуль: [[asyncio]].
2. Обратная связь пользователя и утверждение [[theory-note-template]].
3. Последовательное наполнение остальных тем по [[pareto-plan]].
4. После стабилизации формата — возврат к отложенной задаче развития структуры из [[tasks]].

## Правило актуальности карты

Обновлять эту заметку, когда появляется новый документ верхнего уровня, меняется роль существующего документа, добавляется новый учебный хаб либо изменяется общий маршрут работы. Не перечислять здесь каждую дочернюю теоретическую заметку: её место должно быть видно из карточки родительской темы.

## Контроль версий

Git хранит содержательные заметки волта, `AGENTS.md` и проектные метадокументы. Локальная конфигурация `.obsidian/`, установленные плагины, каталоги Copilot и локальные агентные навыки исключены через `.gitignore`, чтобы diff отражал изменения учебного проекта.
