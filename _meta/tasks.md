# Задачи проекта

Этот файл — источник истины по крупным задачам и их приоритетам. Оперативный следующий шаг хранится в [[state]], требования к основной задаче — в [[theory-note-template]].

## Активная задача — теоретические конспекты

**Приоритет:** самый высокий

**Статус:** подготовка пилота

**Цель:** разработать последовательные теоретические конспекты для всех учебных тем волта, чтобы существующая программа стала полноценным маршрутом обучения, а не только набором тезисов и вопросов для повторения.

### Подход

1. Создать пилотный учебный модуль для [[asyncio]].
2. Пользователь проходит материал и оценивает понятность, глубину, объём, практику и навигацию.
3. По обратной связи скорректировать [[theory-note-template]].
4. После утверждения формата последовательно покрывать темы в порядке [[pareto-plan]].
5. После каждой темы актуализировать [[state]], эту задачу и карту [[index]].

### Критерии завершения пилота

- В [[asyncio]] появился понятный учебный маршрут.
- Теоретические части встроены в `10-python-core/` и связаны wikilinks.
- Материал соответствует [[theory-note-template]].
- Есть объяснения, запускаемые примеры, типичные ошибки, самопроверка и практика.
- Исходные вопросы, чекбоксы, свойства прогресса и «Мои заметки» сохранены.
- Пользователь прошёл пилот и дал обратную связь.
- Итоговый формат зафиксирован как утверждённый или скорректированный шаблон.

### Общий критерий завершения

Все тематические заметки типа `topic` имеют достаточный учебный маршрут или самостоятельный теоретический конспект, прошли проверку связей и соответствуют утверждённому шаблону. Прогресс выполнения следует учитывать по темам, а не по количеству созданных файлов.

## Отложенная задача — развитие структуры проекта

**Приоритет:** отложена до стабилизации формата конспектов

**Статус:** backlog

**Цель:** улучшить организацию волта и тренировочный контур, не отвлекаясь от наполнения теорией.

Возможные направления:

- система повторений с датами последней и следующей проверки;
- журнал попыток и качество ответов, а не только чекбоксы;
- готовые сценарии мок-собеседований;
- банк ошибок и повторяющихся заблуждений;
- шаблон разбора конкретной вакансии;
- матрица доказательств практического опыта;
- улучшение воспроизводимости источников;
- полезные Bases/Canvas вместо пустых заготовок;
- автоматическая или полуавтоматическая проверка целостности wikilinks и свойств.

### План изменения — совместимые ссылки Obsidian и VS Code

**Статус:** backlog

**Цель:** заменить Obsidian-wikilinks вида `[[state]]` стандартными относительными Markdown-ссылками, которые работают в Obsidian, VS Code, GitHub и обычных Markdown-редакторах.

План:

1. Зафиксировать стандарт относительных ссылок в [[conventions]] и `AGENTS.md`.
2. Настроить Obsidian: отключить `Use [[Wikilinks]]` и выбрать `New link format → Relative path to file`.
3. Составить список внутренних wikilinks и разрешить каждый до конкретного файла.
4. Сначала перевести служебные документы: `AGENTS.md`, [[index]], [[state]], [[tasks]], [[theory-note-template]], [[Home]] и [[conventions]].
5. Затем механически преобразовать ссылки в учебных заметках, сохранив подписи, ссылки на заголовки и embeds.
6. Проверить переходы в Obsidian и VS Code, отсутствие сломанных относительных путей, backlinks и граф Obsidian.
7. Обновить шаблоны и инструкции, чтобы новые заметки сразу использовали стандартные Markdown-ссылки.

До выполнения миграции новые конспекты создаются по действующей конвенции wikilinks, чтобы в волте временно не смешивались два незафиксированных формата. Миграцию выполнять отдельным изменением и отдельным коммитом.

К этой задаче не переходить, пока пользователь явно не изменит приоритет либо пока изменение не потребуется для безопасного выполнения активной задачи.

## Правила обновления

- После завершённого изменения отмечать фактический статус, не предполагаемый.
- Новые идеи сначала добавлять в backlog, не расширяя ими текущую работу автоматически.
- Не ставить задачу или тему `done` без выполненных критериев.
- Согласовывать этот файл с [[state]] и [[index]] перед каждым коммитом.
