# Скрининговые вопросы и задачи одним списком

> **Зачем на собесе:** это контрольный лист фазы 1. 26 вопросов технического скрининга на Senior Python + задачи «напиши». Прогнать без подглядывания — критерий готовности к первому этапу. Ответы — в соответствующих заметках по ссылкам.

## Как использовать

Отвечать вслух, по таймеру 2–3 минуты на вопрос. `[x]` — только если ответил уверенно и полно. Провалил — открыть заметку темы, через день вернуться.

## Задачи «напиши код» (15–20 минут каждая)

- [ ] Декоратор `retry(times, exceptions, backoff)` для sync и async функций, с `functools.wraps`.
- [ ] Контекстный менеджер-таймер, который логирует длительность и не глотает исключения.
- [ ] Генератор `chunked(iterable, n)` без загрузки всего в память; `flatten` для произвольной вложенности.
- [ ] Async-функция: скачать N URL с ограничением параллелизма, таймаутом на каждый и сбором ошибок без остановки остальных.
- [ ] LRU-кэш руками (`OrderedDict` или dict + двусвязный список), с объяснением сложности.
- [ ] Rate limiter (token bucket) класс для одного процесса; как перенести в Redis.
- [ ] Парсинг лога: топ-10 IP по количеству запросов, потоково, файл не влезает в память.
- [ ] Класс `Money`/`Vector` с dunder-методами (`__add__`, `__eq__`, `__hash__`, `__repr__`), frozen dataclass.
- [ ] Функция с `Protocol`-зависимостью и её тест с фейком.
- [ ] Рефакторинг: дан «плохой» код (глобалы, длинная функция, бизнес-логика в роутере) — привести к слоям ([[architecture-layers]]).
- [ ] FastAPI-эндпоинт с Pydantic-валидацией, зависимостью на сессию и обработкой доменной ошибки → 409.
- [ ] SQL: запрос «последний заказ каждого пользователя» (window function / DISTINCT ON), «пользователи без заказов», «топ-5 по сумме за месяц».
