# Подготовка к собеседованиям: Python Backend / AI Engineer

Это Obsidian-волт (и одновременно обычный репозиторий markdown-файлов) с планом подготовки к собеседованиям на позицию **Middle+/Senior Python backend с уклоном в LLM-интеграции**.

План построен по принципу Парето: сначала то, что даёт максимальный буст на собеседовании при минимальных усилиях, потом — углубление.

## Как начать

1. Открыть папку как волт в Obsidian (File → Open folder as vault) или просто читать на GitHub.
2. Зайти в [[Home]] — это главный индекс.
3. Прочитать [[how-to-use]] (5 минут) и [[pareto-plan]] (порядок атаки).
4. Выбрать тему из уровня 1, открыть её, идти по чеклисту вопросов.

## Рекомендуемые плагины Obsidian

- **Dataview** — таблицы прогресса в [[Home]] и хабах тем собираются автоматически. Без него всё работает, просто таблицы не отрисуются; используй [[progress]].
- **Tasks** (опционально) — сводка всех незакрытых чекбоксов по волту.

## Как просить дописать/углубить

Структура заметок стабильна, см. [[conventions]]. Чтобы углубить тему, достаточно сказать: «углуби раздел *Углубление* в заметке `asyncio`» — перепишется только этот раздел, остальное (и особенно `## Мои заметки`) не трогается.
